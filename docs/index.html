SideStats

A sidebar that lives on the right edge of your Mac. Move the pointer to the edge and see revenue, ad spend, net profit and ROAS for all your apps — plus servers, dashboards, tasks and anything with an API.

Download for macOS Source on GitHub
Revenue & ad spend

App Store Connect, Google Play, AdMob, AppLovin MAX, Google Ads, Apple Search Ads, Meta Ads — merged per app.

Any API as a module

Grafana, Prometheus, Uptime Kuma, Stripe, GitHub and 40 more integrations, or your own JSON.

Private by design

Runs entirely on your Mac. Credentials stay in your Keychain; there is no SideStats server.

Built for AI agents

Local API and MCP server, so Claude and other agents can add modules and read your numbers.
