Privacy policy

Last updated: November 25, 2026

Summary

SideStats is a macOS app that runs entirely on your computer. It has no backend server, no analytics and no tracking. The developer of SideStats never receives your data.

Data SideStats accesses

  • Google user data (only after you click “Sign in with Google”): AdMob earnings reports (admob.readonly), Google Play reports in your Play developer Cloud Storage bucket (devstorage.read_only) and Google Ads campaign statistics (adwords, used read-only).
  • Apple App Store Connect sales reports and Apple Search Ads campaign reports, using API keys you create.
  • Meta Marketing API ad insights, using an access token you provide.
  • Any other API, command or data source you add yourself as a module.

How the data is used

Data is fetched directly from these services to your Mac and used only to display reports, totals and charts to you inside SideStats. It is cached locally in ~/Library/Application Support/SideStats. Credentials and tokens are stored in your macOS Keychain.

Sharing

SideStats does not transfer, sell or share your data with anyone, does not use it for advertising, and does not use it to train AI or machine-learning models. Data only leaves your Mac when you explicitly configure it to (for example a local MCP client you connect, or a module you set up to call another service).

SideStats' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting your data

Sign out in Settings to delete stored Google tokens; remove keys in each source's settings; delete ~/Library/Application Support/SideStats to remove cached data. You can also revoke SideStats' access at myaccount.google.com/permissions.

Updates

SideStats checks a public feed on GitHub for app updates. This request contains no personal data.

Contact

Questions: open an issue on GitHub.
